## 📖 Overview
<a id="overview"></a>

**AP Tuner** is a practical tuning utility designed specifically for string instruments, making it an essential tool for musicians. This software is available for **Windows** and allows you to tune your guitar, bass, violin, and more without needing a physical tuner. With the **latest version**, you can enjoy a full suite of features that enhance your tuning experience. 

The application works by capturing sounds through a microphone or an electronic instrument adapter, analyzing the audio, and displaying crucial tuning parameters like energy levels, the note being played, and proximity to the next semitone. **AP Tuner** is regularly updated, ensuring you receive the best tools for your musical needs.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Easy Tuning** — Capture and analyze sounds from your string instruments effortlessly.
- **Energy Level Indicator** — Visual feedback on the tuning process to help you stay in tune.
- **Note Played Display** — See the exact note being played for accurate tuning.
- **Semitone Proximity Indicator** — Know how close you are to reaching the desired note.
- **Device Configuration Options** — Customize sound recording from different devices as per your needs.

### Advanced Features:

- **Custom Note Configuration** — Edit note presets to accommodate any string instrument.
